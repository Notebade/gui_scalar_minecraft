# GUI Scalar

Клиентский мод для **Minecraft 1.21.1 / NeoForge 21.1.219+ (ветка 21.1)**, Java 21.

## Использование

Настройки → Настройки графики → «Масштаб GUI: ползунок…».

- Перетаскивание ползунка меняет масштаб интерфейса сразу. После отпускания настройка сохраняется.
- Введите `3.56` или `3,56` в поле и нажмите «ОК».
- Кнопки `−0.01` / `+0.01` и стрелки на ползунке дают точный шаг 0.01.
- «Сбросить на ванильный масштаб / Авто» возвращает сохранённый штатный масштаб Minecraft.

Масштабируется вся стандартная GUI-система: HUD, меню, контейнеры, текст и координаты мыши. 3D-мир и FOV не меняются. Сторонние моды, рисующие напрямую в пикселях, могут потребовать отдельной поддержки.

Диапазон: от 1.00 до `min(16.00, ширина_буфера / 320, высота_буфера / 240)`. Ограничение сохраняет минимум 320×240 логических пикселей для меню. Например, при 1920×1080 максимум 4.50: значения 3.56 и 4.25 доступны. На меньшем окне максимум ниже. После уменьшения окна эффективный масштаб ограничивается автоматически, выбранное значение хранится для восстановления на большем окне.

На первом запуске мод сохраняет поведение ванильного масштаба, пока пользователь не выберет дробное значение. Настройка хранится отдельно в `config/gui-scalar.properties`. Дробные значения могут давать менее резкие края пиксельных текстур — ожидаемый эффект дробного масштабирования.

Во время перетаскивания ползунок сохраняет положение в физических пикселях, чтобы изменение масштаба не обрывало захват мыши. После отпускания меню перестраивается полностью. Ctrl+колесо в настройках графики отключено: штатный обработчик рассчитан на старую кнопку с целыми значениями.

## Сборка

```powershell
.\gradlew.bat build
```

JAR: `build/libs/gui-scalar-1.0.0.jar`. Поместить в `mods` клиента NeoForge 1.21.1. Серверу мод не требуется.

```powershell
.\gradlew.bat runClient
```

`build` запускает также проверку дробных значений, округления и пределов масштаба. Первый запуск Gradle требует интернет для загрузки зависимостей.

Техническая основа: [официальная документация NeoForge 1.21.1](https://docs.neoforged.net/docs/1.21.1/gettingstarted/). Мод меняет аргумент `Window.setGuiScale(double)`, поэтому рендеринг и обработка мыши используют один дробный коэффициент.
