# GUI Scalar — порты 1.21.x

Готовые JAR 1.2.0: `build/ports/`. Устанавливать **один** JAR под свою версию Minecraft, клиент NeoForge. Настройки → **GUI Scalar**. Sodium не обязателен; в портах используется отдельная кнопка настроек вместо зависимости от Sodium Config API.

| Minecraft | Локальная ветка | Рабочий каталог |
| --- | --- | --- |
| 1.21.1–1.21.5 | `port/1.21.1-1.21.5` | `../gui_scalar_ports/1.21.1-1.21.5` |
| 1.21.6–1.21.8 | `port/1.21.6-1.21.8` | `../gui_scalar_ports/1.21.6-1.21.8` |
| 1.21.9–1.21.10 | `port/1.21.9-1.21.10` | `../gui_scalar_ports/1.21.9-1.21.10` |
| 1.21.11 | `port/1.21.11` | `../gui_scalar_ports/1.21.11` |

В каждом каталоге — обычные исходники и `./gradlew.bat build`. Java 21. Версии NeoForge закреплены в `versions.properties`; другая поддерживаемая версия проверяется через `./gradlew.bat '-Pminecraft=1.21.7' build` (пример для ветки 1.21.6–1.21.8).

Проверки: сборка на каждой из одиннадцати версий, границы масштаба, настоящие цели и аргументы mixin, вызовы проекции, список mixin в JAR. Байткод мода сравнивается между версиями внутри группы. Отчёт: `build/ports/verification.json`. Игровая проверка новых версий не выполнялась.

Границы совместимости: 1.21.6 — целочисленный масштаб окна и новый рендер GUI; 1.21.9 — события ввода; 1.21.11 — resize экрана. Начиная с 1.21.10 стандартный ползунок содержит своё поле `dragging`: наши обработчики явно обращаются к `ScaleScreen.this.dragging`, сохраняя захват мыши при живом масштабе.

## Отложенная работа

26.x остановлены по просьбе пользователя. Наработки сохранены в `porting/workbench` (`ports/src/26.*`) и `port/26.1.x`; они не входят в готовые билды. При продолжении перенести явные ссылки на `ScaleScreen.this.dragging` в экспериментальные 26.x, затем повторить проверки. Локальный JDK 25 находится в `.inspect/jdk25/`; для сборки можно передать `-Dorg.gradle.java.installations.paths=...`.

Ветки и коммиты локальные; публикация на GitHub не выполнялась.
